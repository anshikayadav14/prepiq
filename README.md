# PrepIQ 🎯

AI-powered exam preparation platform for Indian students.

## What is PrepIQ?
Upload your notes (PDF, DOCX, PPTX) or paste a website link — PrepIQ converts it into exam-ready study material in seconds.

## Features
- ✍️ **Exam Notes** — Topper-style answers with examiner tips
- 📝 **MCQ Practice** — Auto-generated MCQs with explanations
- ⚡ **Last Minute** — Ultra-compressed notes for 1-2 hours before exam
- 🃏 **Quick Revision** — Flashcards, one-liners, comparisons & formulas
- 🎯 **PYQ Analysis** — Match your notes with previous year questions

## Supported Exams
JEE Advanced, JEE Main, NEET, UPSC, CBSE 10th/12th, B.Tech, CA, GATE and more.

## Tech Stack
- Next.js (React)
- Supabase (Auth + Database)
- OpenAI GPT-4o-mini
- Razorpay (Payments)
